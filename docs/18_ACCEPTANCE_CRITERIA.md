# Acceptance Criteria

## MVP PASS
- Upload works.
- Architecture/Interior selection works.
- 12-layer analysis produces valid structured data.
- Lock rules are enforced.
- Scenario normalizes correctly.
- Master Prompt is compiled from structured data.
- Provider adapter is isolated from core.
- Generation job is traceable.
- Output is stored.
- QC identifies meaningful failures.
- Failed QC can trigger controlled regeneration.
- No secrets are exposed.
- Critical tests pass.

## Product PASS
All MVP criteria plus Reference Intelligence, Editor, Multi-view, Video, Project DNA/versioning, observability, security, performance and production deployment.
