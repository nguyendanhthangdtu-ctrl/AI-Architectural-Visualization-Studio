# Product Constitution

## Product
AI Architectural Visualization Studio.

## Primary user
Architects, interior designers, visualization artists, studios, developers, and teams who have a SketchUp/3ds Max viewport and want realistic final photography.

## Primary workflow
Viewport image → analysis → reasoning → scenario → master prompt → model adapter → generation → QC → correction/regeneration.

## Default output
Real-life photography / professional architectural photography.

## Core modules
- Architecture
- Interior

## Core principles
- Understand before generating.
- Preserve before enhancing.
- Creativity is constrained by permissions.
- Project DNA persists across views and generations.
- Every generated result has provenance.
- Bilingual by design (Vietnamese + English), business/domain data stays language-neutral (see docs/03 §22).
