# AI Analysis Specification — 12 Layers

1. SUBJECT — building/space.
2. ARCHITECTURE — geometry, openings, roof, facade, floor, ceiling, stairs, proportions.
3. STYLE — Modern, Contemporary, Minimalism, Japandi, Luxury, Wabi Sabi, Scandinavian, Tropical, Neo Classic, etc. Default Modern Contemporary when evidence is insufficient.
4. CAMERA — height, lens, FOV, perspective, eye level, projection, vertical correction. Preserve viewport camera when locked.
5. COMPOSITION — leading lines, thirds, golden ratio, symmetry, balance, negative space, hierarchy.
6. MATERIAL — type, finish, roughness, reflectance, microtexture, scale.
7. LIGHTING — direction, time, intensity, softness, shadows, color temperature, artificial lighting.
8. ENVIRONMENT — urban, resort, tropical, garden, forest, coastal, mountain, sky/weather/context.
9. OBJECT/FURNITURE — identify and classify keep/edit/replace/add.
10. PHOTOGRAPHY — camera system look, lens behavior, exposure, dynamic range, depth, imperfections.
11. REAL-LIFE LOOK — professional architectural photography by default.
12. CONSTRAINTS — locks, permissions, user instructions, uncertainty.

Output must be structured data, not only prose. Include confidence/uncertainty where evidence is weak.
