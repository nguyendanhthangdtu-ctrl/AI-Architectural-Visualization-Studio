# Product Requirements

## MVP
1. Create project.
2. Upload SketchUp/3ds Max viewport.
3. Select Architecture or Interior.
4. Run 12-layer AI analysis.
5. Produce Structured Intelligence.
6. Apply Architecture/Camera/Material locks.
7. Select scenario.
8. Compile Master Prompt.
9. Generate via provider adapter.
10. Store result and metadata.
11. Run AI QC.
12. Regenerate with correction instruction when QC fails.

## Post-MVP

- Advanced Editor
- Multi-view
- Sync View
- Creative View
- Project DNA/version tree
- Image-to-video
